# CTSD Home Redesign (Phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the CTSD home page around a WebGL "workshop wall" hero and a pinned showpiece reel, add showpiece-level motion to every section, and refresh the shared header and footer, keeping all existing content.

**Architecture:**
- **Content first:** `public/index.html` stays the content source and must read well with no JS and with reduced motion.
- **Scripts:** `public/assets/js/home.js` renders the data-driven parts (the reel and industry previews) and boots the motion. Live mode lazy-loads two modules, `public/assets/home/wall.js` (three.js hero) and `public/assets/home/motion.js` (GSAP scenes).
- **Media:** loops and posters are generated by `scripts/home-assets.mjs`.

**Tech Stack:** static HTML/CSS/ES modules, a Cloudflare Worker; vendored three.js, GSAP (ScrollTrigger), Lenis; Playwright e2e plus axe; ffmpeg-static and sharp for assets.

**Spec:** `docs/superpowers/specs/2026-10-09-ctsd-home-redesign-design.md`

## Global Constraints

- Palette only: `#3E2723 #6B4F32 #C89B6B #D4AF37 #F7EFE4 #1A1A1A #556B2F #FBF9F6` (the existing tokens in `tokens.css`). Showpiece colors appear only inside the reel's color morph.
- Fonts: Montserrat, Poppins and Inter from `/fonts`.
- h1 is exactly `Technology built around your organization.`. The hero links are "Start Your Project" → `/start` and "Explore What We Build" → `/designs`.
- No `$` character in page text. Every concept is labeled `Concept`.
- Kept content: SERVICES (7), JOURNEY (8), PROCESS (6) with PROCESS_COPY, MANAGE_LIST, INTEGRATIONS (12 text wordmarks, no images), the CTA heading and links, and the four industry links. All as currently asserted in `tests/e2e/home.spec.js`.
- Section order (`main > section[data-section]`): `hero, featured, services, journey, manage, industries, lab, process, integrations, cta`.
- Modes: `html.home-live` (motion) or `html.home-still` (reduced motion or `?still=1`), set before first paint. `html.home-nogl` is added when WebGL is unavailable.
- Vendored libraries only (`/assets/vendor/*`). No new runtime dependencies.
- Media: every `<video>` is `muted playsinline loop preload="none"` with a `poster`, gets its `src` only when near the viewport, and pauses off-screen. Every image except the hero still is `loading="lazy"`.
- First load before scroll is ≤ 1.2 MB (HTML, CSS, JS, fonts, hero still).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

4. **Resizing or rotating mid-page:** the pins must recompute without horizontal overflow. Test: resize from 1280 to 375 on the reel, then check scrollWidth ≤ innerWidth. Owner: Task 5.
5. **WebKit without WebGL:** the `home-nogl` path must show the still wall with the four loop videos over its screens. Test: block getContext('webgl'), then `.wall-screens video` count is 4 and there are no errors. Owner: Task 3.

### Task 3: The workshop wall (WebGL hero)

**Files:**
- Create: `public/assets/home/wall.js`
- Modify: `public/assets/js/home.js` (live boot), `public/assets/css/home.css` (hero layers)
- Test: `tests/e2e/home-motion.spec.js`

**Interfaces:**
- Consumes: `.wall-screens video` elements (Task 2) and the loop URLs (Task 1).
- Produces: `startWall(canvas: HTMLCanvasElement, videos: HTMLVideoElement[], { mobile: boolean, dpr: number }) → { tick(t: number, dt: number): void, setDolly(p: number /*0..1*/): void, dispose(): void }`.

Scene and behavior:
- **Camera:** perspective, fov 35.
- **Slats:** 26 vertical slats as instanced boxes. A shader gives them procedural walnut grain (fbm along y) in `#3E2723`→`#6B4F32`, with slight random depth offsets.
- **Screens:** four 16:10 screens hang on the right two-thirds of the view (desktop) in a staggered 2×2. Each is a `VideoTexture` plane with a thin dark bezel and a soft emissive glow.
- **Lamp:** a SpotLight (warm `#FFD9A0`, angle 0.5, penumbra 0.8) whose target follows the pointer projected onto the wall plane, eased. With no pointer for 3 s, it drifts in a slow figure-eight. Ambient light is 0.25.
- **Screen glow:** each screen's emissive strength is `0.35 + 0.65 * smoothstep(0.6, 0.0, distance(lamp, screen))`.
- **Dolly:** `setDolly(p)` moves the camera along the path from the start pose to a pose where screen 0 fills the viewport (`p=1`).
- **Live boot:**
  - The hero is pinned for `+=160%`. ScrollTrigger maps progress to `setDolly`, and the DOM copy fades out over the first 40%.
  - The canvas fades in over `.hero__img` once at least one video fires `canplay`, or after 2.5 s regardless.
  - Videos get their `src` on boot and are paused while the hero is off-screen (IntersectionObserver).
- **No WebGL (`home-nogl`):** no canvas. `.wall-screens` is laid over `.hero__img` as positioned figures, and their videos play when in view.

### Task 5: Section motion

**Files:**
- Create: `public/assets/home/motion.js`
- Modify: `public/assets/js/home.js` (import in live mode), `public/assets/css/home.css`
- Test: `tests/e2e/home-motion.spec.js`

**Interfaces:**
- Produces: `startMotion({ lenis }) → void`. All scenes are registered with ScrollTrigger and only run in `home-live`.

Scenes:
- **Reel:**
  - Pin `[data-reel]` for `+=300%`. Each item cross-fades in turn.
  - `document.body` gets CSS variables `--reel-bg`, `--reel-fg` and `--reel-accent`, tweened to the item's palette.
  - Each item's video plays only while it is active.
  - `focusin` on a link inside an item scrolls Lenis to that item's progress position (Review Focus 3).
- **Services:** hovering or focusing an `li` in `.strip__list` adds `is-on` to the matching `.sys [data-node]` and its edges. CSS animates `stroke-dashoffset` dots along those edges.
- **Journey:** pin and translate `ol[data-journey]` sideways. The step at the center gets `is-active`.
- **Manage:** the laptop frame tilts with the pointer (quickTo rotationX/Y, max 8°).
- **Industries:** hover or focus on a card plays its `[data-ind-video]` (assigning `src` on first hover) and pauses it on leave.
- **Process:** `[data-process-line]` stroke draws with scroll (scrub). Each `li` gets `is-on` as the line reaches it.
- **Integrations:** two rows of the wordmarks drift in opposite directions, with speed boosted by `lenis.velocity`. The second row is an `aria-hidden` duplicate.
- **CTA:** `[data-lamp]` radial light follows the pointer, and the "Start a Project" button is magnetic.
- **Reveals:** section headings rise with blur, using the shared helper `rise(el)`.
