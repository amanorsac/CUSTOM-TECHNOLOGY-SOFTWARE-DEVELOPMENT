# Kezia Woods: stand-in photo prompts

Generate each image at a 4:5 aspect ratio, for example with Higgsfield `gpt_image_2_5`. Save it as `assets-src/kezia-woods/<slot>.jpg`, `.png` or `.webp`, then run `node scripts/client-assets.mjs kezia-woods`.

None of them may show people, faces, logos or readable text. Her own photos replace them as she sends them, the portrait first.
